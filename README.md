# 🚀 Node.js, Express & MongoDB REST API 🌟

Welcome to my backend project repository! This project is a complete backend REST API built as part of my weekly development milestones. 💻✨

## ✨ Features & What's Inside:
* 🌐 **Express Server & Routing:** Clean and structured RESTful endpoints (`/api/tasks`, `/api/interns`, etc.).
* 🗄️ **MongoDB & Mongoose:** Persistent database storage ensuring data survives server restarts, complete with schemas, validation, and timestamps.
* 🔄 **Full CRUD Operations:** Create, Read, Update, and Delete operations fully tested and working.
* 🛡️ **Security & Protection:** Secured using `Helmet` and `CORS` middleware.
* ⚠️ **Robust Error Handling:** Input validation, try/catch blocks, 404 route handlers, and a global error catcher.
* 📬 **Postman Collection:** Fully documented and exported API collection.

## 🚀 Getting Started Locally:
1. Clone Repository

```bash
   git clone <repo-url>
```

---

## Install dependencies:

```bash
npm install
npm i helmet dotenv express mongoose cors nodemon
```

---

## Create a .env file and provide your connection string:

```bash
MONGODB_URI=your_mongodb_connection_string
PORT=port
```

---

## Start the server:

```bash
npm run dev
```
